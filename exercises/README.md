# Exercises

One folder per topic (`fde-1-01/`, `fde-1-02/`, …), added as production reaches
each topic. Every exercise ships with:

- `README.md` — the task, its constraints, and what "done" means
- starter code and any provided inputs (messy on purpose, where the topic is mess)
- automated tests or a grading rubric
- `SOLUTION.md` — the reference solution, released after the attempt window

Exercises are part (d) of each topic's four-part lesson. They are designed to
be attempted before watching the tutorial half of the lesson.
