# FDE 1.02 Exercise — Read the business, find the workflows

**Topic:** Reading a customer's business (Layer 1). **Part (d) of FDE 1.02.**

## The task

Read `company-brief.md` (Harbor Lane Outfitters, a fictional retailer).
In `workflows.md`, name **three** candidate workflows worth automating.
For each: the workflow as it runs today, the metric it moves, the baseline
the brief supports (or "unknown — measure first" where it does not), and
who inside the company is paid to care about that metric.

## Done means

- Exactly three workflows, each tied to a number in the brief or an honest
  unknown — never an invented baseline.
- Each metric is one the business already counts or can count this week.
- One workflow is ranked first, with the reason stated in one sentence.
- Graded with `RUBRIC.md`. `SOLUTION.md` is the reference answer, released
  after the attempt window.
