# FDE 1.02 Reference solution

Released after the attempt window. One defensible answer:

1. **Returns triage and reason capture (rank 1).** 18% of orders return at
   about $11 handling each, run by a two-person desk. Metric: handling cost
   per return and reason-coded return rate. Baseline is in the brief, the
   owner is obvious (operations), and reason data feeds buying decisions.
2. **Support ticket triage.** 6,400 tickets a month, up 40%, categories in a
   personal spreadsheet. Metric: tickets handled per agent-day and first-
   response time. Baseline partially unknown — the spreadsheet must be
   audited first; say so rather than inventing category shares.
3. **Morning stock truth for stores.** Managers phone the warehouse because
   inventory is a day old. Metric: stock-check calls per store per day.
   Baseline unknown — measure first for one week. Owner: store operations.

Checkout abandonment (71%) is the trap answer as a first pick: the number is
real but nobody owns the funnel, so no one can sign for the delta.
