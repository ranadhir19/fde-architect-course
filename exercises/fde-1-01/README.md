# FDE 1.01 Exercise — Classify the work

**Topic:** The role, from first principles (Layer 1). **Part (d) of FDE 1.01.**
Attempt this before watching the tutorial half of the lesson.

## The task

`tasks.json` holds 12 real-world-style task descriptions. For each one, name
the role that actually owns it — one of `fde`, `sales-engineer`,
`solutions-architect`, `consultant`, `product-engineer` — and defend the call
in one line. The deciding test from the lesson: who writes production code
inside one customer's systems after the sale, and who is measured on the
number moving?

## Starter

Copy `classify_starter.py` to `classify.py`, fill in `ANSWERS` with a role
and a one-line reason per task id, then run the tests.

## Done means

- All 12 classifications submitted (the tests check the role calls).
- Every call defended in one line that names the deciding fact (pre-sale vs
  post-sale, one customer vs many, builds vs advises, stays vs hands over) —
  graded with the rubric in this folder, by a human or a study partner.
- `SOLUTION.md` in this folder is the reference answer key; it is released
  after the attempt window for the lesson.
