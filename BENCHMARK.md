# Benchmark — how this course is scored

This course claims to be the most comprehensive Forward Deployed Engineer
course available. Claims are cheap; this file is the measuring instrument.

The scorecard adapts Quality Matters (certification at ≥85% of points **and**
all Essential standards met), the Achieve OER rubrics, the worked-example
effect, deliberate-practice research, and Mayer's segmenting/signalling
principles.

**The bar: ≥85% of total points AND full marks on dimensions 1, 8, and 9
(the Essentials) — scored per phase by a fresh-eyes reviewer before that
phase publishes. Scores are published here, including the misses.**

| # | Dimension | What is measured |
|---|---|---|
| 1 | Quality / Accuracy *(Essential)* | Claims traced to primary sources; code runs; numbers verified |
| 2 | Depth | All nine capability layers taught at advanced level, not mentioned |
| 3 | Explanation | Worked example before theory; a whiteboard derivation per topic |
| 4 | Engagement | Retention and completion vs the channel's own course baseline |
| 5 | First-principles fundamentality | Every topic derived from the role's primitives, mapped to a layer |
| 6 | Problem complexity | Ambiguity, legacy mess, mid-project change, failure events in practice work |
| 7 | Ease of learning | Dependency order respected; prerequisites stated; zero forward references |
| 8 | Practice & Assessment *(Essential)* | An exercise per topic with tests/rubric; capstones graded on published rubrics |
| 9 | Transfer to the job *(Essential)* | Capstone deliverables identical to real FDE artefacts (decision log, eval report, rollout plan, walkthrough) |
| 10 | Production & packaging | Channel certification gates passed for every lesson |
