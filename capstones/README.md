# Capstones — simulated customer engagements

Each capstone is a fictional customer engagement with real FDE deliverables.
Briefs live here; messy inputs (data extracts, legacy system stand-ins, ticket
history) are added per capstone as production reaches it.

**Universal deliverables** (every capstone): a running system, `DECISIONS.md`,
an eval report, a rollout plan, and a 5-minute recorded walkthrough.
**Universal twist:** every engagement includes a mid-project **change
injection** — the customer's reality changes after you have started, because
that is what actually happens on deployment.
