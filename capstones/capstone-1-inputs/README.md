# Capstone 1 — Provided inputs (all fictional, all synthetic)

The customer is Cedarbrook Home Goods, the fictional retailer
used across the Phase 1 exercises. Every file here was generated
for this course; no real customer data exists in this pack.

| File | What it is |
|---|---|
| `tickets.csv` | 2,000 historical support tickets from last quarter, as exported — not cleaned |
| `returns-policy-current.md` | The returns policy exactly as published on the customer's policy page at engagement start |
| `returns-policy-change-injection.md` | The week-2 change injection. Open it only when your attempt reaches week 2 — opening it early is reading the exam's second half first |
| `rota.csv` | The support lead's rota spreadsheet, exported as-is. Per FDE 1.08, this sheet is the single source of truth for the rota |

## What is wrong with `tickets.csv` (the shape, not the map)

You are told the shape of the mess, because an FDE is told the
shape by the customer. Finding the instances is the work:

- Categories were merged from **three legacy systems** two years
  ago. The same customer intent appears under different raw
  labels depending on which system the ticket came through.
- There are **exact duplicates under different ticket ids**
  (about 3% of rows) — merged inboxes double-filed them.
- Some rows have **silently empty fields**: no category, or no
  body. Nothing marks them; the export simply omits the value.
- Priority casing is whatever the legacy system felt like
  (`High`, `HIGH`, and `high` are the same priority).

Your data audit (FDE 2.01 will formalise this) starts here:
report the counts you find for each defect class before you
build anything on this data. A triage system trained on the
raw export inherits all four defects.

## Generation note

`tickets.csv` was generated by a seeded script (seed 20261123)
so the dataset is identical for every learner and every defect
count in the reference solution is reproducible. Subjects and
bodies are drawn from fixed per-intent templates; the realism
target is the *structure* of a merged legacy export, not
literary variety.
