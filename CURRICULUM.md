# Curriculum — Forward Deployed Engineer, The Complete Course

Three phases, built bottom-up on a nine-layer capability stack. Every topic is
taught in four parts: (a) learning session, (b) whiteboard explanation,
(c) coding session, (d) tutorial + exercise (in `exercises/`).
